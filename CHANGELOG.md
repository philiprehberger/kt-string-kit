# Changelog

## [0.1.0] - 2026-03-18

### Added

- `truncate()` and `truncateWords()` for smart string truncation

- Case conversion: `toCamelCase()`, `toSnakeCase()`, `toKebabCase()`, `toPascalCase()`, `toTitleCase()`, `toConstantCase()`

- `collapseWhitespace()`, `initials()`, `surround()`, `wordWrap()` utilities

- `interpolate()` for map-based `{key}` template substitution
